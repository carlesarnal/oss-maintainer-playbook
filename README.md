# Beyond the First Pull Request

An ownership-aware contribution workflow, grounded in Apicurio Registry's public
process and an actual review. This is a presentation and workshop repository,
not a claim that automation proved contributor growth.

## Evidence

- [PR lifecycle](https://github.com/Apicurio/apicurio-registry/blob/main/.github/PR_LIFECYCLE.md)
  separates waiting on authors from waiting on maintainers. Maintainer-only
  inactivity gets an overdue signal rather than author-directed auto-closure.
- [PR #10409](https://github.com/Apicurio/apicurio-registry/pull/10409) records
  Carles's approval, a pending full verification gate and the later merge.

The policy includes a trade-off: when **both** sides are blocked, its contributor
timer takes precedence. A reviewer suggestion is not proof of accepted ownership,
and a green fast check is not a passed full test suite.

Use `handoff.md`, `PRESENTATION_GUIDE.md` and `presentation.html`. No particular bot
is required to adopt the ownership conventions. The published document was
inspected; the entire automation implementation and its outcomes were not audited.
